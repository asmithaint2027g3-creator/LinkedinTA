# TRUSTGRID.AI — Brand & Content Guide for LinkedIn

## 1. Company Positioning
- **Official Name**: TRUSTGRID.AI (stylized as TrustGrid.AI or TRUSTGRID)
- **Positioning**: Enterprise AI Engineering Operating Company for the AGI Era.
- **Core Mission**: Bridging the critical execution gap between enterprise AI experimentation (pilots, POCs, slide decks) and industrial-grade enterprise execution (production AI factories, autonomous agent swarms, deterministic governance, and measurable financial attribution).
- **Delivery Model**: Forward Deployed Engineers (FDEs) and dedicated Domain-Agentic Delivery Pods executing directly within sovereign client infrastructure (DBOT: Design, Build, Operate, Transfer).

## 2. Target Audiences & Personas
1. **CTOs, CIOs & AI Infrastructure Leaders**
   - *Concerns*: GPU cluster utilization (turning 30-40% idle silicon into 80%+ efficiency), 30–100kW direct-to-chip liquid cooling, Blackwell vs Hopper architecture transitions, high-throughput inference serving, RoCEv2/InfiniBand fabrics.
   - *Tone*: Systems-engineering rigor, hardware-software co-design, deterministic SLAs.
2. **Heads of AI, Automation & Enterprise Operations**
   - *Concerns*: Moving past single prompt chatbots to autonomous multi-agent systems, persistent agent memory (episodic, semantic, procedural), agent orchestration swarms, human-in-the-loop oversight rails, eliminating operational friction.
   - *Tone*: Operational precision, workflow autonomy, integration with enterprise systems of record.
3. **CISOs, Security & Governance Leaders**
   - *Concerns*: Agentic attack surfaces, prompt injection/jailbreak at runtime, zero-trust IAM for autonomous agents, Cryptographic Bill of Materials (CBOM), Post-Quantum Cryptography (PQC), EU AI Act, NIST AI RMF compliance, explainable AI (SHAP/LIME).
   - *Tone*: Rigorous threat modeling, board-defensible audit trails, sovereign data boundaries.
4. **CFOs, Finance & Transformation Executives**
   - *Concerns*: AI Pilot sprawl, runaway inference and training costs, FinOps for AI, unit economics per cognitive task, total cost of ownership (TCO), financial attribution of AI ROI.
   - *Tone*: Commercial value, financial accountability, capex/opex efficiency.

## 3. Brand Visual Identity Standards
- **Aesthetic**: Sovereign, industrial-grade enterprise technology. Minimalist, high contrast, technical clarity, structured diagrams, zero decorative stock imagery.
- **Primary Color Palette**:
  - `Deep Navy / Slate`: `#0B132B`, `#0F172A`, `#1E293B` (Backgrounds, primary canvas, high-authority cards)
  - `Electric Cyan / Tech Blue`: `#0284C7`, `#0EA5E9`, `#38BDF8` (Focal accents, data paths, badges)
  - `Emerald / Trust Green`: `#10B981`, `#059669` (Verification, security, governance, ROI proof points)
  - `Canvas White / Slate White`: `#FFFFFF`, `#F8FAFC`, `#F1F5F9` (Text contrast, clean card fills)
  - `Muted Slate`: `#64748B`, `#94A3B8`, `#CBD5E1` (Labels, supporting specs, secondary lines)
- **Typography**:
  - Primary UI & Visual Headers: System Sans-Serif (`Inter`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`)
  - Code & Data Metrics: Monospace (`ui-monospace`, `SFMono-Regular`, `Consolas`, `Liberation Mono`)
- **Visual Asset Specifications**:
  - Format: SVG (Scalable Vector Graphics) with embedded styles and crisp typography.
  - Aspect Ratio: Portrait 4:5 (`1080 × 1350 px` viewBox `0 0 1080 1350`), optimized for LinkedIn mobile and desktop feed visibility.
  - Safe Area: `60px` padding on all sides to avoid feed truncation.
  - Header: TrustGrid.AI logo mark / typography + Category pill + Topic ID.
  - Footer: Verified TrustGrid.AI badge + Brand signature + Call to action.

## 4. Post Formats & Authoring Standards

### Image-Based Posts (60 Topics)
- **Components**:
  1. `post.md`: 150–250 word LinkedIn caption framing the visual problem, technical context, key framework takeaways, and verified CTA.
  2. `visual.svg`: 1080x1350 standalone high-resolution diagram/infographic.
  3. `visual-brief.md`: Design specifications, cognitive visual hierarchy, data flow, color mapping, and accessibility alt text.
  4. `metadata.json`: Machine-readable metadata schema.

### Text-Based Posts (40 Topics)
- **Components**:
  1. `post.md`: 200–350 word complete text post featuring:
     - 1–2 line pattern-interrupt hook.
     - Enterprise tension / industry reality check.
     - 3–5 bulleted architectural or strategic principles.
     - Strategic decision takeaway or question.
     - Verified TrustGrid.AI diagnostic/briefing CTA.
     - 3–5 professional hashtags.
  2. `metadata.json`: Machine-readable metadata schema.
  *(Note: No visual files created for text-based topics).*
